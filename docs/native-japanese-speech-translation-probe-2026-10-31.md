# ネイティブ日本語5分の音声通訳ストレス試験（2026-10-31）

## 目的と試料

現行候補のGPT-Live `plain-q`を、既存の不動産対談とは独立した日本語話者・内容で確かめた。試料は[京都大学のCoVoST 2 Native Japanese](https://github.com/ku-nlp/covost2NativeJa)のtest split（CC BY 4.0）から、文と英訳が付いた89発話を決定的な順序で選び、0.9秒の無音を挟んで300秒へ連結したもの。3人のネイティブ話者を含み、質問候補21件を配置した。否定候補23件・数量候補22件も文字列規則で分散させたが、義務形や慣用句も混じるため、これらを「事実ラベルが人手で確定した件数」とは扱わない。

独立した読み上げ文を連結しており、自然な対談や話者交替の検証にはならない。音声・原文・付属英訳・訳音声・区間別判定はGit管理外の私有研究フォルダに保存し、この公開リポジトリには入れない。

## 手順

24 kHz mono PCM16を200 msフレームで実時間送信し、末尾20秒の無音で残りの訳出を待った。出力**音声**をローカルwhisper.cpp `small.en`で単語時刻化し、CoVoSTの日本語文を参考原稿としてCodex判定器v3で89区間を照合した。遅延は原語区間開始から対応する英語音声の理想再生時刻までの`L_start`。字幕到着時刻は代用していない。原語転記の文字誤り率は、句読点・空白を除いたデータセット文と、モデルの逐次原文転記を連結した文字列とのLevenshtein距離で求めた。

| 項目 | GPT-Live `plain-q`、5分1回 |
|---|---:|
| 原語転記の文字誤り率 | 9.62%（137 / 1,424文字） |
| 対応づいた区間 | 88 / 89 |
| `L_start`中央値 / 95百分位 | 3.50秒 / 5.38秒 |
| `L_start` 8秒以内 | 87 / 88（98.9%） |
| 訳音声の再生待ち行列最大 | 0.78秒 |
| 意味点（0–3）の平均 | 2.43 / 3 |
| 意味3点 / 0–1点 | 58 / 89、19 / 89 |
| 質問候補のうち「質問を答えに変えた」判定 | 2 / 21 |
| 欠落 / 創作の判定フラグ | 10 / 8 |
| 出力音声のローカルASRとモデル字幕の語一致 | 97.5%（coverage 93.5%） |
| fatal / 末尾切断警告 | なし / なし |
| API費用の推定 | 約$0.30 |

低評価には、球場への徒歩の主体を別人にした例、鳥のひなと親鳥の関係を別の情景へ変えた例、質問を約束の文にした例、住宅設備を別の語として訳した例が含まれる。原文・付属英訳・音声ASRを89件並べた私有照合表を作成した。**速度はこの連結短文では目標に近いが、重大な意味誤りを許す品質ではない。**既存の自然会話5分では`L_start`の95百分位が8秒を超えるrunもあり、この試験の速度を製品の対面会話へ一般化しない。

## 判定の限界と次の順序

原語文はデータセット付属文で、89音声を人がすべて聴き直した正解原稿ではない。英語音声のASRにも誤認識があり、意味点・フラグは機械判定である。今回の参考原稿に重要事実の個別ラベルを入れていないため、集計器の`criticalFactErrors=0`は**誤りゼロを意味しない**。付属英訳と訳音声を人が比較し、質問・主体・否定・数量の誤りを確定する必要がある。

次は[Kotoba STS](simultaneous-interpretation-landscape-2026.md#75-kotobaの日英直接音声通訳と評価上の注意2026-10-31)を**同じWAV・同じ判定器**で比較する。そこで重大な事実誤りが減る場合だけ先読み`delay`を増やして品質優先のA/Bを行う。独立した自然会話と日英話者のブラインド聴取まで、製品の既定エンジンは変えない。MSLTの自然会話コーパスもローカルに取得して連続5分の私有試料を作ったが、研究・非商用のライセンスなのでクラウドAPIへ送らず、権利条件を確認した範囲のローカル分析に留める。
