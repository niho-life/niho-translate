# NIHO Translate

iPhoneとマイク付きイヤフォンを使う、最大4人・日本語/英語の対面音声通訳。

開発中です。実機での音声品質・遅延・連続動作の受入はまだ完了していません。

通訳のSDKと音声配信をこのリポジトリで開発します。利用者の認証、本人情報、実際の資格情報と運用予算は、ホストアプリケーションが管理します。合成データだけで開発・CIを実行します。
